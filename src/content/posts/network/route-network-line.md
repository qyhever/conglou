现在有两台路由器设备，分别是 AX1800 和 AX3000T。

## 开启两个独立 wifi
如果需要开启两个独立 wifi，那么前提是两个 wifi 不能在一个 IP 段，需要隔离开来。

### 一、两台路由WAN直连光猫（并联接法）
两台路由器的 WAN 分别直连光猫的 LAN1 LAN2
```
             光猫
           /      \
        LAN1      LAN2
         │          │
      AX1800     AX3000T
```

#### 优点
1. 两台路由器**完全独立**，网段互不干扰，不存在 IP 冲突问题，不用改副路由LAN网关
AX1800默认192.168.31.1，AX3000T可以继续保留192.168.31.1也没事，互不影响
2. 其中一台路由死机、重启，**另一台网络不受影响**
3. AX3000T跑满宽带性能不受前面AX1800限制，带宽独立
4. 各自WiFi可以设置完全不一样网段，设备之间隔离，安全性更好

#### 缺点
1. 需要宽带**允许多设备同时拨号**，部分套餐限制只能1拨，接上也上不了网（如果光猫已经完成了拨号，那么两台路由器则无需再拨号，直连光猫即可）
2. **两个路由器下面设备不能互相访问**（AX1800的设备访问不到AX3000T的设备，不能共享文件、游戏互联、投屏、访问NAS）
3. 光猫要多出一个空闲LAN口

### 二、AX1800 LAN → AX3000T WAN（二级路由串联接法 WAN级联）
光猫 LAN → AX1800 WAN，AX1800 LAN → AX3000T WAN
```
光猫 LAN
 ↓
AX1800 WAN
 ↓
AX1800 LAN
 ↓
AX3000T WAN
```

#### 优点
1. **只需要一次拨号**，由主路由AX1800拨号，副路由不用填宽带账号密码，不怕运营商限制多拨（如果光猫已经完成了拨号，这里是没有影响的）
2. 布线灵活，不用跑线到光猫，从AX1800那边拉网线就行
3. 副路由自带防火墙隔离内网

#### 缺点
1. **天生容易IP网段冲突**（两台都是小米默认192.168.31.1），必须手动修改副路由LAN网段
2. AX3000T网速上限受主路由AX1800转发性能轻微制约（千兆宽带下AX1800压力不大）
3. 主路由AX1800一旦断网，副路由一起断网
4. 默认情况下**两个路由内网设备也不能互通**（存在两层 NAT 隔离，想要互通还要额外设置）

#### 如何配置
一级路由AX1800 不用动，二级路由 AX3000T 需要进入路由器管理页面设置

##### 管理员密码
-  **第一次通电全新状态**
  1. 手机连上路由器出厂开放WiFi（`Xiaomi_xxxx`，无密码）
  2. 浏览器打开 `192.168.31.1` 或者 `miwifi.com`
  3. **直接弹出设置向导，不需要输入旧密码**，跟着页面走：
      - 设置WiFi名称、WiFi密码
      - 默认勾选：**把WiFi密码同时作为路由器管理密码**（网页后台登录密码=你设置的WiFi密码）
      - 也可以取消勾选，单独设置一个管理员密码。

-  **如果打开页面直接弹出密码输入框（不是设置向导）**
  说明路由器不是全新未配置状态（已经设置过）：
  1. 尝试输入你家WiFi密码（绝大多数人都是WiFi密码=管理密码）
  2. 不行就恢复出厂：拿牙签或取卡针长按Reset小孔10秒，灯闪烁松开，等待启动完成，再重新走首次设置流程。

##### 进入管理页面
1. 浏览器打开 `192.168.31.1`, 输入密码成功登录
2. 上网设置 - 上网方式 确保是 DHCP 方式
3. 局域网设置 - DHCP服务，设置 IP 段为 192.168.50.1 - 192.168.50.254
4. 局域网设置 - 局域网IP地址，设置 IP 为 192.168.50.1
5. 保存重启路由器
6. 后续该路由的新管理页面地址为 `192.168.50.1`

##### 接线
二级路由 AX3000T 设置好后，就可以接线到 一级路由 AX1800 了

两个路由号段不同，相互独立

## 开启两个同名 wifi
按照上面的两种接法，并联接法和二级路由 WAN 级联接法，就算 WiFi 名称、密码、加密全部一模一样，也做不到无缝漫游，切换一定会断一下网。

只有 LAN‑LAN AP 模式（同一局域网、同一个 DHCP 分配 IP） 才有漫游基础条件。

### 1、并联接法
两台是**完全独立两套网络、两个不同网段、两套DHCP网关**
- WiFi名字一样只是**同名不同网**
- 手机从A走到B：断开A路由连接 → 重新认证 → 获取一套全新IP与网关 → 连上B路由
- 切换中断：**1～3秒断流**，视频会卡停、游戏直接460掉线、语音通话可能直接挂断
- 问题根源：IP地址彻底变了，原有网络会话全部失效
> 哪怕两台网段碰巧一样，拨号链路独立，底层路由完全隔离，依然不是同一个局域网，不能漫游。

### 2、二级路由WAN级联（AX1800‑LAN → AX3000T‑WAN）
双层NAT，**两个独立子网，各自DHCP**
主路由：192.168.31.x
副路由：192.168.50.x（不能和主路由冲突）
- 同样同名WiFi，切换时手机**更换IP、更换网关**
- 切换断流 0.8‑2秒，游戏、直播、微信语音容易掉线
- 就算网页刷着看不出卡顿，长连接业务一定会断
> 通俗讲：一个家里两个独立小区大门，门牌网段不一样。

### 3、LAN‑LAN AP模式对比（唯一具备漫游基础）
将 二级路由WAN级联 调整下

```
光猫 LAN
 ↓
AX1800 WAN
 ↓
AX1800 LAN
 ↓
AX3000T LAN
```

整个网络**只有一套DHCP，全部设备同一个网段，IP切换时保持不变**
切换只是换一个无线信号发射点，IP不动，网络会话保留。
- 普通同名AP：**伪漫游**，手机自己决定什么时候切，大约200‑600ms卡顿，偶尔短暂丢包，日常视频基本可用，游戏还是不稳
- 小米有线Mesh（两台组成Mesh）：**真漫游802.11k/v/r**，最佳推荐，原生快速漫游，切换<100ms，几乎无感知不掉线，非常适合全屋走动WiFi不掉线

### WiFi粘滞
两台路由器设备距离很远时更加明显，信号重叠区域很小：手机迟迟不肯切换（WiFi粘滞），走到很远信号很差网速暴跌才被迫断开重连，断网时间更长。

### LAN‑LAN AP模式接线和配置
AX1800 LAN → AX3000T LAN

配置阶段：先不接线，手机直连AX3000T的WiFi先改参数，改完重启再插网线，避免IP冲突进不去后台。

1. 手机连AX3000T默认WiFi，浏览器打开 `miwifi.com` / `192.168.31.1`
2. 【局域网设置】修改LAN口IP：
一级路由AX1800网关为：`192.168.31.1`
二级路由AX3000T LAN IP改为：**`192.168.31.2`**，子网掩码`255.255.255.0`
> 不要填别的网段，要同网段，以后管理二级路由就访问 `192.168.31.2`
3. **关闭DHCP服务器**，二级路由不再分配IP，全部由AX1800分配IP。
4. 保存 → 路由器重启。
5. 重启完成后，再插上AX1800‑LAN到AX3000T‑LAN的网线。

#### WiFi设置
WiFi名称、密码、加密(WPA2‑PSK/WPA3)和AX1800完全一样；  
2.4G信道手动错开，例如AX1800用1，AX3000T用11；5G信道也错开，不要自动信道。

> 测试连接wifi时，更新路由设置后，wifi 需要手动删除，主动释放路由器分配的 IP，再次连接，重新分配 IP

#### 有线mesh
有线组网：
1. 将未配置过的子路由WAN口与主路由LAN口通过网线连接
2. 将子路由上电，启动完成后将自动进行组网，组网时子路由Internet指示灯快闪，指示灯变为常亮，自动完成 Mesh 组网

注意：
1. 子路由 AX3000T 不能做过任何配置，必须恢复出厂，如果之前设置过 AP / 二级路由，一定要重置
2. 子路由脱离主路由网线，会自动降级为无线 Mesh；插回网线自动切回有线回程
